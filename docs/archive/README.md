# Historical archive

These files record earlier audits, implementation passes, verification results, content updates, and handoffs. They are preserved as evidence, not current architectural authority. No archived document or screenshot content was changed.

The old HANDOFF predates Journal V2 and claims assets/ is empty. The readiness and deprecation reports describe the earlier root-owned token distribution; current ownership is documented in VERSION_STRATEGY.md and v2/V2_ARCHITECTURE.md. PROJECT_MEDIA_BLOCKERS is a point-in-time inventory, not live project data. HOMEPAGE_V1_TO_V2_MIGRATION_MAP (moved here in cleanup pass 2, from the repository root) is superseded as the authority on current Homepage behavior by `../HOMEPAGE_FUNCTIONAL_PARITY_AUDIT.md`, which states explicitly that earlier migration reviews are historical evidence, not proof of current behavior; the migration map's section-by-section content is retained here as historical evidence only. Reports with pending work retain that information; no blocker was resolved by this cleanup.

The ten screenshots had no references in the inspected HTML, CSS, JavaScript, JSON, Markdown, or text files. Their ongoing value is uncertain, so all were preserved under screenshots/ rather than deleted. No screenshot was assumed redundant solely from its filename or size.

Original relative paths and inline filenames inside archived documents are historical and remain unchanged. Root-level document references now resolve by looking up the same filename here; references to application files are relative to the repository root. Use the exact old-to-new mapping in [the manifest](../HYGIENE_MANIFEST.md).
